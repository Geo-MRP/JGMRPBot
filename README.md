## Info

The objective of this open-source initiative is to ensure the long-term development, maintenance and survivability of technology initially made by [ghost_of_denver](https://discord.com/users/1510279232201298022) for the [GeoFS Military Roleplay Community](https://discord.com/invite/updVrRXm4P) on Discord.

This repository aims to cover the Discord bot behavior of GMRPBot. That is, it's going to be a Discord bot with multiple different Commands and Loops, among other things, to serve the GMRP Community.
